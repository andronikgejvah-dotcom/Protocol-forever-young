# Библиотека картинок для верхней части рилсов

| Папка | Для каких упражнений |
|---|---|
| `jaw/` | челюсть, подбородок, скулы, овал лица |
| `neck/` | шея, лимфодренаж, ключицы |
| `eyes/` | глаза, веки, гусиные лапки |
| `forehead/` | лоб, морщины на лбу |
| `lips/` | губы, носогубка |
| `before_after/` | «до/после», в т.ч. для начала ролика (`*_HOOK`) |

Новые картинки кладутся в нужную папку со следующим номером: `jaw_04.jpg` и т.д.
